# Cerebro

A personal research agent with persistent memory, powered by FalkorDB.

Cerebro remembers what you've researched across sessions — entities, facts, and sources are stored as a knowledge graph, so it can recall and connect information from session 1 while you're in session 5, instead of starting cold every time.
